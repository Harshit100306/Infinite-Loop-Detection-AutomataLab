The theoretical boundary

Why a universal detector cannot exist.

HALT = { <P, x> | program P halts on input x }

For unrestricted programs, no algorithm can decide HALT correctly for every program-input pair.

D(P) = opposite behaviour of P(P)

A hypothetical perfect decider leads to a contradiction when applied to a program that deliberately does the opposite of the decider's prediction.

A heuristic warning is not a proof of non-termination. “No pattern found” is not a proof of termination.

03 · Decidability vs recognizability

Halting is recognizable by simulation when the program eventually halts, but its complement is not recognizable in the unrestricted setting.

Finite-state cycle monitor

Demonstration of exact cycle detection for a deterministic finite-state system.

s₀ → s₁ → s₂ → … → sₖ

Because the state space is finite, a deterministic run either reaches a terminal state or eventually repeats a state. A repeated state proves a cycle in this model.
